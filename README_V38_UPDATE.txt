EARTH WORKS WEBSITE - V38 CATALOG PREPARATION

This release is based on the approved V37 ZIP.

1. Landscape Supplies dropdown
   The former 12-category menu is replaced with the eight categories provided by the client, in the requested order. Each links to a category-specific page.

2. Contact Us / Get a Quote form
   Added the optional question "How do you plan to receive your products?" with Pickup, Delivery, and Install checkboxes (multiple choices permitted), plus a Delivery/Install Address text input. Existing form fields and prototype submission behavior have not been changed.

3. Product listings
   Product cards have been removed from all existing collection pages and legacy category layouts. New category pages have empty product lists with a neutral message until the updated catalogue is provided. Existing product detail page files and all original image assets have been retained, but they are no longer linked from the category lists.

No other approved sections, copy, colors, typography, or functional flows have intentionally been changed.
