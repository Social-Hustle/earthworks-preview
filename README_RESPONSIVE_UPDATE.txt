EARTH WORKS - DESKTOP AND MOBILE UPDATE

Open index.html, or deploy the complete directory to the existing static host.
This package remains the editable HTML/CSS/JavaScript prototype.

TYPE SETTINGS
The original font families and global paragraph/heading styles are retained.
Component-specific settings are in assets/earthworks-v29-responsive.css:
  --ew29-announcement-size: announcement only (responsive on narrow screens)
  --ew29-category-label-size: category-menu links only
  --ew29-category-width: category rail width paired with those labels
  --ew29-header-row-size: shared desktop black/white row height
  --ew29-logo-width: desktop logo size
  --ew29-action-height: compact mobile action bar
Do not change global p, small or h3 rules to adjust these two header text roles.
The file uses the existing ew21-components CSS layer so overrides have consistent
precedence over earlier component styles.

DESKTOP
Announcement and category-menu labels are larger.
Black and white header rows share a height; the original logo is displayed larger.
The second, third and fourth homepage category cards contain the supplied copy.
The first card's wording and imagery are unchanged.

MOBILE (UP TO 767 PX)
Only the white logo/navigation row is sticky. The announcement and black service
promise row stay in normal flow and scroll away.
Hamburger left, logo centered, cart icon right. Language and My Account controls
move into the menu as icon-only controls. The header quote button is hidden.
The existing full search field is replaced by the bottom search-icon entry point.
Bottom actions use 20% Call, 20% Search and 60% Get a Quote, in a 52px bar plus any
safe-area inset. Quote uses the existing green button gradient.
Call opens a chooser for Indian Springs (205-982-9922) or Birmingham (205-942-3311).
The hero occupies at least half the viewport. Its original asset is unchanged;
responsive framing preserves the headline and DRT, with sky from the same image.
The call-us banner reflows the original image lettering into two lines using SVG
viewports. No replacement font or regenerated artwork is used.
Review/project carousels retain native swiping; their arrow controls are hidden.
The center project-description paragraph is hidden on mobile; the heading remains.
Footer yards form one two-column row; Quick Links / Customer Service form another.
The large footer wordmark is hidden on mobile only.

Existing tablet layout structure is retained for the separate tablet design pass.
Account, cart and language controls retain their existing prototype notices.
No checkout, account backend or live translation has been added.
No original image, logo or font asset was replaced or regenerated.
