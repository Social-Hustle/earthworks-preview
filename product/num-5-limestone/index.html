Before you order

Questions worth answering first.

Landscape materials are easier to buy when the page answers the same questions the yard team would ask. Use this checklist before requesting pricing.

Size / gradeConfirm the nominal size or grade with Earth Works, especially when comparing similarly named stones.
Project functionTell the yard whether the material is for decoration, drainage, a base, a path, a driveway or masonry.
Traffic + compactionVehicle traffic, foot traffic and whether the surface must compact can change which material is appropriate.
Depth + quantityBring the area dimensions and planned depth so the team can help you discuss quantity.
Edging + slopeLoose decorative stone can behave differently on slopes or without edging; describe the site conditions.
Delivery accessIf you need delivery, share the address and any access constraints before the load is scheduled.

Product questions

What customers usually want to know.

Where the current website does not publish an exact specification, the page says so and directs the customer to confirm it with Earth Works.

How is this different from similar stone grades?

#5 Limestone is a distinct product/grade in the Earth Works range. When two products share the same stone name but use different grade numbers, size is a key distinction. Confirm the current nominal dimensions and appearance with the yard before ordering.

Which limestone grade should I choose?

Start with the intended use—base, surface, drainage or site work—and the desired particle profile. Earth Works carries several limestone grades, so the yard can help narrow the options for your project.

How much do I need?

Measure the project length and width and decide the intended installed depth. Share those dimensions with Earth Works so quantity can be discussed without adding a calculator to this Phase I site.

Will the color and size look exactly like the photo?

Natural stone can vary between loads and quarry material. Treat the website image as a visual guide and confirm current stock if appearance is important.

Is this material washed or screened?

The current live website does not publish wash or screen specifications for every individual stone. Ask the yard if that characteristic matters for your application.

Can Earth Works deliver it?

Earth Works advertises delivery options. Provide the material, quantity, job address and site-access details so delivery can be confirmed.
